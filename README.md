# 🦋 Caza Mariposas 3D

Juego 3D desarrollado en Unity con C# como proyecto final del curso de Desarrollo de Videojuegos.

## 🎮 Descripción
El jugador debe cazar mariposas antes de que toquen el suelo en un escenario 3D decorado con naturaleza.

## 🕹️ Controles
- **WASD** — Mover al personaje
- **Escape** — Pausa

## ⚙️ Mecánicas
- +5 puntos al cazar una mariposa
- -1 punto cuando la mariposa toca el suelo
- 90 segundos de partida
- Panel de fin de partida con puntuación final

## 🛠️ Tecnologías
- Unity 6
- C#
- GitHub
- Unity Asset Store
